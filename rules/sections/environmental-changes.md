# Section 7: Environmental Changes

## What this section is for

In the agency's assessments this narrative covers the changes in the child's environment that bear on treatment: transitions (a new school, a move, a new sibling, a change of caregiver), changes in routines, and the supports planned to help the child through them.

## How to write it

- Only changes the sources report, each attributed: who reported it, when it happened or will happen, and how the child has responded, with the concrete behavior when given.
- Supports planned: only those the sources or the BCBA's notes name (for example a visual schedule introduced at home). If a change is reported and no support is planned in the sources, say what was reported and mark the support [MISSING: support planned for ...] rather than proposing one.
- If the sources report no environmental changes, write one sentence saying that none were reported, naming who was asked when the sources say so.
